## 风险和停止点

- API 服务未启动、健康检查失败或浏览器未登录：停止页面操作，记录阻塞原因。
- Provider 没有可用凭据：不把它当作前端缺陷；分别检查页面是否显示明确提示，并将真实模型测试标为环境阻塞。
- 发现接口会写入不可恢复数据：停止写操作，先记录已完成的只读结果。
- 发现产品问题：只写验证报告，不修改产品代码。
