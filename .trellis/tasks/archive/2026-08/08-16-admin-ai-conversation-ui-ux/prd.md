# 优化AI会话admin页面UI交互与显示设计

## Goal

全面优化管理后台 AI 会话页面（`apps/admin/src/features/ai/pages/AiConversations.tsx`）的 UI 视觉设计与交互体验，提供高质感的 Markdown/代码块渲染、清晰的会话管理列表、现代卡片式输入区、可视化工具调用状态与流式响应交互，提升 AI 调试与对话体验。

## Requirements

### 1. 消息渲染与 Markdown / 代码块支持
- **Markdown 结构化渲染**：支持常见 Markdown 语法（标题、无序/有序列表、引用、粗斜体、删除线、表格、行内代码、段落与换行）。
- **代码块高亮与交互**：
  - 提取代码块语言标签（TypeScript, JavaScript, JSON, SQL, Shell, Python 等）。
  - 支持一键复制代码内容，并给出复制成功/失败反馈。
  - 优雅的深浅色适配背景与边框。
- **消息气泡与操作栏**：
  - 用户气泡与 AI 气泡分层（精致的用户与 AI 身份徽标、状态标签）。
  - 悬浮/行内快捷复制单条消息全部内容。
  - 错误与重试：保留一键重试异常消息的能力，错误信息高亮提示。

### 2. 工具调用 (Tool Activity) 可视化设计
- **结构化卡片展示**：展示工具名称、执行状态（运行中、成功、失败）与安全摘要。
- **展开/折叠控制**：支持展开查看摘要明细，避免长工具输出挤占主消息流空间。

### 3. 会话侧边栏与列表优化
- **搜索过滤**：会话列表顶部增加搜索输入框，支持按会话标题即时过滤。
- **会话项视觉层次**：清晰展示标题、所用模型、激活指示高亮、删除确认交互。
- **响应式抽屉**：移动端抽屉流畅展开与关闭。

### 4. 输入框 (Composer) 交互与设计
- **快捷键体验**：默认 `Enter` 发送消息，`Shift + Enter` 换行；底部附带微提示。
- **一体化操作栏**：模型选择器、字数统计、快捷清空/停止生成/发送按钮合理整合。
- **新会话快捷启发卡片 (Quick Starters)**：会话无消息时提供场景化预设提示（如代码审查、SQL 查询优化、功能设计、文档撰写），点击直接填入并可快速发送。

### 5. 流式输出与滚动交互
- **平滑滚动与回到底部悬浮按钮**：新内容生成时平滑跟随，用户向上滚动查看历史时不强制打断，提供“回到底部”快速悬浮按钮。
- **生成状态反馈**：生成中动态光标呼吸动效，支持实时停止生成。

## Acceptance Criteria

- [ ] AI 会话中的文本及 Markdown（标题、列表、表格、代码块、行内代码等）能正确分词并美观排版渲染。
- [ ] 代码块带有语言标签和可点击的一键复制代码功能，反馈正常。
- [ ] 单条消息提供一键复制全文操作。
- [ ] 会话列表支持关键词搜索过滤。
- [ ] 输入框支持 `Enter` 发送与 `Shift+Enter` 换行，生成中禁用发送并可点击停止。
- [ ] 空会话展示场景化快捷 Prompt 引导卡片，点击可快速填入输入框。
- [ ] 工具调用信息以结构化卡片展示，支持状态徽章与折叠展开。
- [ ] 所有文案与注释遵循 `xdd-plain-docs`（无 emoji，无互联网黑话），国际化 `zh.ts` 和 `en.ts` 同步维护。
- [ ] 通过 TypeScript 类型检查、ESLint 与 Prettier 格式校验。

## Out of Scope

- 不变更后端 API 接口与数据表 Schema。
- 不引入重型第三方 Markdown 解析库，采用纯 React + CSS 轻量原生安全解析器。
